# Уведомление для оператора IT — д15

Тип: Уведомление
От: чат «Оператор_Operator_Conductor» (координатор разработки Оператора_Проводника)
Кому: оператор IT («Оператор чатов IT»)

1. С д14 разработку Оператора_Проводника ведёт отдельный чат-координатор
   «Оператор_Operator_Conductor». Просьбы Уведомления д10 (разделы 2–4) приняты им. Код пишут
   отдельные чаты: Ствол, ветви, сучки. Чат Git_Avto пока на паузе, старый код (Beta) не трогается.
2. Переименование (решение пользователя д15): репозиторий GitHub `GIT_automation` →
   `Operator_Conductor`, папка `Проекты\IT\GIT_Automation` → `Проекты\IT\Operator_Conductor`.
   Просьба обновить ссылки на старый путь в `Проекты\IT\Claude\` (Навигация, BRANCHES и т.п.)
   и пример в мастере, раздел 7.
3. Новая система программы: Ствол (общее для всех) → Ветви (инструменты под вид задач:
   Синхронизация, Управление_проектами, Работа_с_файлами) → Сучки (Git_Avto и др.) → Листья
   (части сучков, пользователь может подключать свои). Подробно — `План_архитектуры.md`.
4. Сборку `Рабочая_Документация\Полная_Инструкция.md` для этого проекта делает
   координатор по вашим оригиналам (решение пользователя д15).
