# Вопрос в чат IT — логи (от чата GIT_Automation, 26.09.2026)

Пользователь просит сделать логи AutoSync (GIT_Automation) по тому же принципу, что уже сделан в
Godot_Template (https://github.com/Glebmzs7/Godot_Template). Распишите, пожалуйста, как там
устроено логирование, чтобы повторить его в AutoSync:

1. Где лежат файлы логов и как называются (папка, шаблон имени, дата/время запуска в имени?).
2. Новый файл на каждый запуск программы — или иначе (по дням, по размеру)?
3. Сколько файлов хранится и как удаляются старые (по количеству, по возрасту, вручную)?
4. Формат строки (время, уровень, источник/модуль, текст) и уровни (INFO/WARN/ERROR?).
5. Есть ли отдельный лог ошибок/крашей и как он связан с основным.
6. Что показывается пользователю в интерфейсе (весь лог, только текущий запуск, фильтр?).
7. Путь к классу/файлу в репозитории (например `Class_Logger.gd`), чтобы можно было сверить.

Текущее состояние AutoSync для сравнения: один общий `Сам проект/Save/autosync.log` (у Beta-копии
~200 КБ за 3 дня), отдельный `Save/autosync_crash.log` для падений; журнал в окне показывает
хвост общего файла + текущий запуск.

Ответ можно положить сюда же, в `Claude/GIT_Automation/` (например `Ответ_IT_логи.md`).
