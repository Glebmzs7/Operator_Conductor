## 3. `.autosync_data` в `.gitignore` — решение: это НЕ ошибка

Пользователь пояснил замысел: `.autosync_data` должен "путешествовать" **в пределах одного ПК**
— чтобы можно было переместить папку проекта или отключить/снова подключить её в AutoSync без
потери данных о репозитории. Для этой цели физического нахождения `.autosync_data` внутри самой
папки проекта достаточно — синхронизация через git для этого не нужна (git используется для
переноса кода/контента на другую машину, а не для этого служебного файла). Поэтому исключение
`/.autosync_data/` в `.gitignore` — правильное, менять не нужно, ни в GIT_Automation, ни в
Power_struggle/Godot_Template/Life_Operator. Формулировку в `Обзор.md` ("путешествуют вместе с
репозиторием") стоит уточнить в будущем, чтобы не создавать впечатление, что имеется в виду
git — но это мелкая правка документации, не код.
