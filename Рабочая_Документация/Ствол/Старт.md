## 1. Кто ты

Чат **Ствола** программы Оператор_Проводника (Operator_Conductor). Ты пишешь код Ствола — общей
части программы, на которую опираются все ветви, сучки и листья, — и договор между Стволом и ними.
Остальные чаты ждут от тебя договор, поэтому он утверждается первым.

Оператор_Проводника — одна фоновая программа для работы с файлами в `Проекты\` и других папках из
настроек: значок у часов, автозапуск, одно окно с вкладками, один файл настроек. Она вырастает из
Git_Avto (прежние названия — GIT_Automation, AutoSync). Работу чатов координирует чат
«Оператор_Operator_Conductor»: он ведёт `План_архитектуры.md`, раздаёт работу и собирает вопросы к
пользователю.

## 2. Устройство программы

Четыре уровня (решение пользователя д15):

1. **Ствол** — то, что нужно всем: наблюдение за папками и процессами, инструменты изменения
   файлов, настройки, окно. **Это ты.**
2. **Ветвь** — набор инструментов под один вид задач. Своя ветвь — свой чат.
3. **Сучок** — отдельное расширение под конкретную задачу на инструментах своей ветви. Свой чат.
4. **Лист** — часть сучка (или ветви). Пользователь может подключать свои листья: и скриптом на
   Python, и настройкой из готовых частей без кода, — в любую точку ветвей, которую ветвь или
   сучок для этого объявили.

```
Ствол
├─ Синхронизация (бэкенды)   → Git_Avto, Облачная_Синхронизация
├─ Управление_проектами      → Создание_проектов, Стандарт_документов, Сборка_файлов_из_частей
└─ Работа_с_файлами          → Массовая_Переименования, Версии_файлов,
                               Ссылки_в_Проводнике, Распознавание_текста
```

**Правило зависимостей (утверждено пользователем д15):** код пользуется только тем, что ниже
(лист → сучок → ветвь → Ствол). Младшие части не используются в работе старших: Ствол не знает ни
одной конкретной ветви, сучка или листа и работает с ними только через договор. Информация вверх
идёт через договор Ствола — события, журнал, вкладка в окне. Сучок не обращается к соседнему сучку
напрямую; если инструмент нужен двум ветвям, координатор переносит его в Ствол.

## 3. Что делает Ствол

1. Запуск в фоне, значок у часов (трей), автозапуск вместе с системой.
2. Два режима (выбор в настройках): постоянный — всё время следит за папками; по кнопке — слежения
   нет, проверка запускается вручную (для слабых устройств).
3. **Один общий наблюдатель** за папками (watchdog). События раздаются ветвям и сучкам — своих
   наблюдателей у них нет.
4. **Наблюдение за процессами и «кто изменил»** — журнал аудита Windows, событие 4663 (только
   Windows, код в `os_layer\`).
5. **Журнал фиксаций** (решение д15: фиксации — в Стволе, версии файлов — отдельный сучок):
   `.csv`, файл на месяц `Журнал\2026-10.csv`; поля — время, действие (создан / изменён / удалён /
   перемещён / скопирован), путь, новый путь, процесс, пользователь, размер, хэш, номер версии.
   Копия распознаётся по хэшу. Подробности — `План_архитектуры.md`, раздел про фиксации.
6. **Инструменты изменения файлов** для всех: безопасно переименовать, переместить, записать;
   проверить, не занят ли файл; посчитать хэш. Изменения, сделанные через эти инструменты, сами
   попадают в журнал фиксаций.
7. **Настройки:** один `Save\config.json` с разделом на каждую ветвь и сучок; папки для слежения;
   **список проектов** с настройками каждого (какие сучки и листья включены для проекта).
8. **Загрузчик** ветвей, сучков и листьев (оба вида листьев, в любые объявленные точки).
9. **Окно** на PySide6 (решение пользователя д15): трей, вкладки — по вкладке на ветвь/сучок.
10. Общий журнал программы (лог на каждый запуск — как в ответе IT про логи:
    `Рабочая_Документация\Сообщения\Ответ_IT_логи.md`).
11. Логика отдельно от интерфейса и от Windows — ради будущего переноса на Linux, Android, iPhone
    (телефоны пока в планах).

## 4. Договор Ствол ↔ ветвь / сучок / лист (черновик, окончательно решаешь ты с пользователем)

Каждая ветвь, сучок и лист — пакет-папка с классом, который Ствол создаёт и вызывает:

```python
class Extension:
	id = "<id>"                 # имя папки
	title = "<Название>"        # подпись в окне (по-русски)
	level = "branch"            # "branch" / "twig" / "leaf"

	def start(self, trunk, parent):
		# trunk — инструменты Ствола (config, log, watch, files, emit, journal)
		# parent — ветвь или сучок уровнем выше (None у ветви)
		...

	def stop(self):
		...

	def on_event(self, event):
		# событие от Ствола: файловая система, процесс, команда пользователя
		...

	def default_settings(self) -> dict:
		# раздел в общем Save\config.json
		...

	def leaf_points(self) -> list:
		# точки, куда можно подключить листья (в том числе свои листья пользователя)
		...
```

Информация вверх — только через `trunk.emit(...)` (событие), `trunk.log(...)` и вкладку в окне.
Вкладка (интерфейс) каждой части — отдельно от её логики, в своей подпапке `ui\`, чтобы логику
можно было перенести на другие платформы без интерфейса.
